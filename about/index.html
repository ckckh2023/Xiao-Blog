隐私政策

本站高度重视你的隐私，整体遵循「最小化收集、不追踪、不贩卖」原则：

  • 留言板：仅存储你主动填写的昵称、正文与头像信息。IP 地址经 SHA-256 加盐哈希后存储，不保存原始 IP，仅用于 10 分钟频率限制。
  • 头像获取：可选填写 QQ 号以获取头像，QQ 号本身不存储，仅生成头像 URL。
  • GitHub 数据：项目页通过 GitHub API 拉取公开仓库信息，使用 ETag 条件请求与本地缓存，不涉及你的账号数据。
  • 无第三方追踪：不使用 Google Analytics、百度统计等追踪脚本，不写入追踪 Cookie。
  • 主题偏好：深浅色模式选择存储于浏览器 localStorage，不上传服务器。
