🗑️ TrashGo 智识助手

C++ Qt 6.10 OpenCV 4.12 ONNX MIT ★ 14 · ⑂ 2 · 更新于 2026-08-12

TrashGo 是一款集多种图像信息识别功能于一体的桌面端智能工具，基于 Qt 6 + OpenCV 构建，支持 4 大类 120 种细分类别的垃圾分类识别，提供本地 ONNX 模型离线识别与百度云 API 双引擎切换，并附带投放建议、识别记录、收藏夹与个性化设置。

核心功能

  • 图像识别：上传图片即可识别 4 大类 120 种细分类别，返回类别名、置信度与投放建议。
  • 双引擎切换：本地 ONNX 模型（ResNet / MobileNet）离线推理，或调用百度云图像识别 API，可在设置中一键切换。
  • 识别记录：本地 SQLite 持久化历史识别结果，支持按时间、类别筛选与导出。
  • 收藏夹：对常用或易混淆类别加星收藏，快速检索。
  • 个性化设置：明暗主题、配色方案、API Key 管理、模型路径配置。

识别流程

  1. 上传图像：拖拽或选择本地图片进入识别区。
  2. 引擎推理：按当前引擎调用本地 ONNX 或百度云，得到 Top-K 候选类别。
  3. 结果呈现：展示主类别、细分类别、置信度与投放建议，并写入历史记录。

分类一览

4 大类 · 120 种细分类别，每种均附投放建议：

  • 可回收物：纸张、塑料、金属、玻璃、织物等
  • 厨余垃圾：剩饭剩菜、果皮、蛋壳、茶渣等
  • 有害垃圾：电池、灯管、药品、油漆、杀虫剂等
  • 其他垃圾：烟蒂、纸巾、陶瓷、灰土等难分类项

使用提示

首次使用本地模型需将 ResNet.onnx / MobileNet.onnx 放入 model 目录；选择百度云引擎需在设置中填入 API Key 与 Secret Key。
