项目档案 技术笔记 自组装 最近更新 · 2026-08-13

本 Wiki 用于整理我的项目档案与开发笔记。左侧侧边栏按分组导航，/docs 下每个文件夹即一页，新增条目只需新建文件夹并写入 index.html，再在 assets/js/manifest.js 中登记一条即可被自动收录到本目录与侧边栏。

结构说明

/
├── index.html                    # 博客首页
├── assets/
│   ├── css/main.css              # 共享样式
│   └── js/
│       ├── manifest.js           # wiki 目录清单
│       └── wiki-layout.js        # 共享侧边栏组件
└── docs/
    ├── index.html                # 本页（目录首页）
    ├── trashgo/index.html        # 项目档案：TrashGo
    ├── btir/index.html           # 项目档案：BTIR
    └── notes/index.html          # 技术笔记

每个 docs/<folder>/index.html 引入相同的 manifest.js 与 wiki-layout.js 渲染侧边栏，主体内容直接写在 HTML 中，无需构建步骤。
