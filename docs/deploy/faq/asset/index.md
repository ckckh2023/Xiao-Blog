# 资源加载失败

页面能打开但 CSS / JS / 图片 404，常见原因：

- **路径用了相对路径而部署在子路径**：项目页（`用户名.github.io/仓库名`）下资源需用 `./` 相对路径或 `/仓库名/` 前缀
- **Jekyll 忽略了下划线开头的目录**：如 `_css`、`_js` 不会被发布，加 `.nojekyll` 关闭 Jekyll 处理
- **文件大小写不匹配**：Git 默认不区分大小写，本地能跑线上 404，统一用小写命名
- **CNAME 与资源域名不一致**：自定义域名下资源仍用 `用户名.github.io` 域名会跨域失败

建议资源路径统一用根相对路径（`/assets/...`），并在仓库根放 `.nojekyll`。
