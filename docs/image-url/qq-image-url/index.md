腾讯通过 qlogo.cn 提供了一套稳定、无需鉴权的公开接口，仅凭 QQ 号即可获取用户头像。

---

## 接口地址 ##
```text
https://q1.qlogo.cn/g?b=qq&nk={qq号}&s={尺寸}
```
---

## 参数说明 ##

| 参数 | 含义 | 有效值 | 
| --- | --- | --- | 
| b	| 固定值 | qq | 
| nk | 目标 QQ 号 | 纯数字 | 
| s | 头像尺寸（px）| 40、100、140、640等常见尺寸 | 

举个例子：
如果 QQ 号是 12345678，那么它的头像地址是：

|尺寸 | 直链 | 
| --- | --- | 
| 40px | https://q1.qlogo.cn/g?b=qq&nk=12345678&s=40 | 
| 100px | https://q1.qlogo.cn/g?b=qq&nk=12345678&s=100 | 
| 140px | https://q1.qlogo.cn/g?b=qq&nk=12345678&s=140 | 
| 640px（高清） | https://q1.qlogo.cn/g?b=qq&nk=12345678&s=640 | 

---
## 调用方式 ##

- 浏览器：直接将链接粘贴至地址栏即可查看。<br>
- HTML：放入 `<img src="...">`属性中正常引用。<br>
- 程序：GET 请求返回图片二进制数据，可直接使用。<br>

---
## 注意事项 ##

- 尺寸限制：s 值并非任意整数，官方常见值为 40、100、140、640。
- 头像缓存：接口有较强 CDN 缓存，更换头像后可能存在延迟。
- 隐私与默认头像：若用户未设置自定义头像，或设置了仅好友可见，此接口仍会返回默认系统头像，不会返回空白或报错。
- 协议：仅支持 HTTPS，不支持 HTTP。
