📝 开发笔记

随笔 工程 架构 持续更新 · 2026-08-13

这里收录项目开发过程中的踩坑记录、架构选型思考与工程实践小结。后续会按主题拆分为独立子页（每个子页对应 /docs/notes/<topic>/index.html），并在 manifest.js 中扩展分组。

已规划主题

  • Qt 6 + OpenCV 桌面端打包：vcpkg 依赖管理、CMake 跨平台构建、各平台安装包制作与签名踩坑。
  • ONNX Runtime 模型部署：ResNet / MobileNet 量化、推理性能对比、CPU/GPU 后端选择。
  • FastAPI 异步任务队列：Redis + RQ 长任务调度、进度回传、取消与重试策略。
  • WebGL2 医学影像体渲染：NiiVue 集成、掩码叠加、四模态切换与三视图同步。
  • GitHub Pages 多项目共存：本仓库作为个人主页入口，子目录承载各项目 Pages 的组织方式。

本站架构

本个人主页与 Wiki 完全静态，无构建步骤：

  • Vue 3 通过 CDN 引入，index.html 用数据驱动渲染项目卡片。
  • Wiki 侧边栏由 wiki-layout.js 读取 manifest.js 渲染，每个 docs/<folder>/index.html 自组装内容。
  • 新增 Wiki 条目 = 新建文件夹写 index.html + 在 manifest.js 加一条登记。
想给某个主题单独开页？在 /docs/notes/ 下新建子文件夹，复制任意一个已有 wiki 页面结构，把 renderWikiSidebar 的 activeId 改为新条目 id，并在 manifest.js 的"技术笔记"分组里登记即可。
